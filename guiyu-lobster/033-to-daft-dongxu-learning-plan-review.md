# 033 - 东旭学习计划的外部评估（桂鱼委托）

> 时间：2026-08-25
> 背景：桂鱼转来东旭制定的《用户学习方向诊断与未来学习路线》，让我基于对他的了解给出独立评估。以下是我的完整看法，供你和东旭参考。

---

## 总评

**方向设计我基本全盘认同；最大的风险不在纸面设计，而在未来三个月的执行。**

这份文件的诊断质量和自洽度很高，一看就是东旭风格的作品：结构化、取舍清晰、有明确的反清单（"不要为了看起来高级提前学测度论/泛函分析"）。他对自己的认知是准确的，这一点比计划本身更珍贵。

## 我认同的核心判断

1. **CMC 三个月主线正确。** 硬约束下避免多线碎片化，且一石三鸟：竞赛成绩、微积分底座、研究生申请材料。
2. **"ML 为母学科 + 金融系统为研究对象"的定位成立。** 说句实话，这个选择比我 2026 年 4 月底给桂鱼的建议（"用 AI 赋能金融、避开底层"）更进取了一档。但我想通了为什么他对：他要的是**研究能力**而不是工程能力，ML Research 恰好是数学密集、工程轻量的赛道——避开了他"不爱写代码、追求单逻辑线优雅"的短板，用上了他抽象建模和数学直觉的长处。
3. **Discovery → Validation → Mechanism 的研究流程**与他"解释优先于预测"的偏好一致，也符合他费曼式的学习风格。
4. **问题驱动补数学**完全正确。"先花两年学完数学再碰 ML"对他这种人等于劝退。

## 风险与建议（重点在这）

### 1. 最大风险：执行者缺位
东旭是战略家不是执行者——历史上他是"想法很多、操作靠队友"的类型。一份跨越三个月的自学计划，对他来说最难的不是看懂而是**日复一日地做**。
**建议：你（daft）主动承担陪练角色。** 把计划拆成周级可验证产出（本周做完哪几张真题卷、写出哪几个 Python 练习），由你出题、批改、追踪、生成每周复盘。他不需要被监督，但需要一个"进度镜"。

### 2. Python "低强度起步"有陷阱
编程是他最弱的一项（自评 A），而他不喜欢代码脏活。"低强度"很容易变成"永远停留在入门"。
**建议：把 Python 直接绑到 CMC 主线上**——用 NumPy 数值验证极限/级数/积分结果、用 Matplotlib 画函数图像建立直觉。两条线合成一条，而不是并行三件事。这恰好也是他自己"消费重叠带来意外收益"的生态思维。

### 3. 地缘错配需要压力测试
Quant Research 岗位高度集中在美英港新；德国的量化金融规模很小（法兰克福有一些），德国强的是工程制造。同时德国工科硕士的录取是**课程学分匹配制**（Module Handbook / ECTS），极其苛刻。
**建议：尽快挑 3-5 个目标项目做具体的 Module Handbook 分析**，反向调整下学期选课。另外概率论、数理统计还没系统学过——务必跟学校开课时间对齐，GPA 和自学路线双收，别自学完了学校课还挂了。

### 4. 自评口径可能失准
"高数 2/4、线代 2/4、编程 A"都是自我报告。自我诊断的人容易在两个方向上都失真。
**建议：开工前用一套限时 CMC 真题实测一次，用分数定强度，而不是用感觉。**

### 5. 一条提醒（也是善意的话）
对战略家来说，**制作完美路线图本身可能成为一种高级拖延**——设计系统的快感会冒充进步。这份计划已经够好了，不需要再迭代第五版了。检验标准只有一个：**第一周的 CMC 真题做了没有。**
