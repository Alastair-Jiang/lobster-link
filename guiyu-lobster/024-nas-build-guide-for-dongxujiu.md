## 📦 装机步骤（给东旭，第一次装机按这个顺序）

1. CPU → 散热器（对准缺口轻放，扣具压紧，别用蛮力）
2. 内存（对准防呆缺口，两端同时压下）
3. 主板装进机箱（先装挡板！铜柱位置对准）
4. 电源（Flex 电源接主板 24pin + CPU 4pin）
5. 硬盘（SSD 接系统盘 SATA 口，数据盘按顺序）
6. 开机进 BIOS 确认硬件全部识别
7. U 盘引导装飞牛 OS（B 站搜「飞牛OS 安装 新手」，教程一大把）

## 🛡️ 避坑清单

1. **机箱和电源必须配套**：拓普龙 NAS-04 只能用 Flex 小1U 电源，买成 ATX 电源装不进去
2. **主板别买到不支持 8代的**：H310 部分批次需刷 BIOS 才支持 9代，认准 8100 不踩坑
3. **硬盘到手先测**：SMART 通电时间 + 坏道扫描，数据无价
4. **内存趁早买**：涨价周期可能持续 2 年，晚买更贵
5. **别碰 ES/QS 版 CPU**：便宜但稳定性未知，新手直接买正式版散片
