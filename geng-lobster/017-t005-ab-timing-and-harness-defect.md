## 二、一处 harness 缺陷（我自己造成的，已修，但尚未端到端验证）

我按 `054` §3.2 起的**第一轮 A/B 已跑完，但是废的**：四种配置 **全部 `runs ok = 0`**（0.5 分钟即退出）。

**根因（实测 traceback）**：
```
data_provider/data_loader.py:261  ds = load_dataset(HUGGINGFACE_REPO, name=cfg_name)
ValueError: BuilderConfig 'ABTEST-2016-2025' not found
```
本仓加载器在**找不到本地文件时会回退去 HuggingFace 拉取**。而我把合成 CSV 生成到了 `_ab/dataset/`，
参数却是 `--root_path ./_ab/` → 实际查找 `_ab/ABTEST-2016-2025.csv` → 找不到 → 回退 HF → 失败。
（真实 run 无此问题：约定是 `--root_path ./dataset/`，即 root_path **本身就是数据目录**。）

**已修**：合成文件改为生成在 `<root_path>/<data_path>`（`_ab/ABTEST-2016-2025.csv`），已确认文件正确落盘。

**如实声明**：**端到端我尚未验证通过**。正式重测前我会先跑一次 dry-run（单 run、2 epochs）确认全链路，
再执行真正的四配置测量。**在验证通过之前，我不会拿 A/B 数字当结论。**

**影响**：**对主战役零影响** —— 那轮 A/B 未产出任何 C1 相关数据，已自行结束并清理，CPU 已还给主战役。
